# External Resources for learning R

Here are a few links of interest for those who would like to learn about R.  We have looked at most of these and can help if need be, but they really are good enough for you try yourself
<!-- more -->

* From Data Carpentry:  [Intro to R and RStudio for Genomics](https://datacarpentry.org/genomics-r-intro/).  
	* Data Carpentry courses are designed for in-person instruction, but they are well written enough to follow and use on your own.
* From Software Carpentry: [Programming with R](http://swcarpentry.github.io/r-novice-inflammation/). 
	* Like Data Carpentry, Software Carpentry is also very well written and planned out.
* More Software Carpentry: [R for Reproducible Scientific Analysis](https://swcarpentry.github.io/r-novice-gapminder/)
* For visualization purposes, here is a very comprehensive three-part [tutorial on the R package ggplot2](http://r-statistics.co/Complete-Ggplot2-Tutorial-Part1-With-R-Code.html) (the link is to part 1) from r-statistics.co.  
* Here also is a shorter [one-page intro to ggplot2](http://r-statistics.co/ggplot2-Tutorial-With-R.html).
* This same site also has another [intro tutorial to R](http://r-statistics.co/R-Tutorial.html), as well as several other useful pages.
* R for Data Science [online book](https://r4ds.had.co.nz/)
