⚠ Biology pitfalls to avoid
Unstated organismYou'll get human biology.
Paralog collapseSay symbols are mapped orthologs; flag merged paralogs.
Symbols onlyUse stable IDs (Ensembl) and name the convention.
No build / versionsState genome build and package versions.
Memory recallNever ask for citations or numbers from memory.
Story as analysisRun the enrichment test first, then interpret.
Leading question"If my interpretation isn't supported, say so first."
